STEP 1

계정·Gmail 서비스 연결

화면에서 누를 위치

  1. EmailJS 대시보드 로그인
  2. Email Services → Add New Service
  3. Gmail 선택 → Connect Account
  4. Account → General에서 Public Key 확인

붙여넣을 값

Service IDservice_igeigtl
Public KeyLebdq6Hu0Ac0XOJ6I

Service ID는 EmailJS의 Email Services 화면에 표시된 값과 정확히 같아야 합니다. 입력한 값과 화면의 ID가 다르면 홈페이지 코드의 Service ID도 실제 값으로 맞춰야 합니다.

STEP 2

접수 알림 템플릿 만들기

화면에서 누를 위치

  1. Email Templates → Create New Template
  2. Settings에서 수신·발신 항목 입력
  3. Content 편집기 우측 상단 코드 보기(< >) 선택
  4. 아래 알림용 HTML 전문 붙여넣기 후 저장

붙여넣을 값

Topssharon73@gmail.com
From Name{{from_name}}
Reply To{{from_email}}
Subject[문의] {{inquiry_type}} - {{from_name}}
Bcc(대안)pssharon@naver.com

사용 변수: from_name, from_email, phone, company, inquiry_type, message, to_email, reply_to, submitted_at, page_url, privacy_agreed, agreed_at

STEP 3

문의자 자동회신 템플릿 만들기

화면에서 누를 위치

  1. Email Templates → Create New Template
  2. Settings에서 자동회신 항목 입력
  3. Content 편집기 우측 상단 코드 보기(< >) 선택
  4. 아래 자동회신용 HTML 전문 붙여넣기 후 저장

붙여넣을 값

From NameAI 강사 박정숙

email_template_autoreply.html 전문

STEP 4

Gmail에서 네이버 메일로 자동 전달

화면에서 누를 위치

  1. Gmail 설정 → 모든 설정 보기
  2. 전달 및 POP/IMAP → 전달 주소 추가
  3. 네이버 메일에서 확인 메일 인증
  4. Gmail 검색창 우측 옵션 → 조건 입력 → 필터 만들기
  5. 다음 주소로 전달 선택

붙여넣을 값

전달 주소pssharon@naver.com
필터 제목[문의]

EmailJS가 내 Gmail로 보내는 메일은 자기발신 메일로 처리되어 전달 필터가 적용되지 않을 수 있습니다. 이 경우 STEP 2의 접수 알림 템플릿 Settings에서 Bcc에 pssharon@naver.com을 넣으세요.

STEP 5

Gmail에서 문의 내역 자동 분류

화면에서 누를 위치

  1. Gmail 검색창 우측 검색 옵션 표시
  2. 제목에 [문의] 입력
  3. 필터 만들기 → 라벨 적용
  4. 필요하면 받은편지함 건너뛰기(보관) 선택

붙여넣을 값

제목 조건[문의]
라벨 예시홈페이지/교육문의
STEP 6

실제 문의 전송으로 동작 테스트

화면에서 누를 위치

  1. 홈페이지 문의 폼에서 필수값과 개인정보 동의 입력
  2. 맞춤 교육 문의 보내기 선택
  3. 브라우저의 성공 안내 확인
  4. Gmail, 문의자 메일, 네이버 메일, Gmail 라벨 순서로 확인

확인할 결과

  1. Gmail에 접수 알림 도착
  2. 문의자 이메일에 자동회신 도착
  3. 네이버 메일로 전달 또는 Bcc 수신
  4. Gmail 문의 라벨 자동 적용
